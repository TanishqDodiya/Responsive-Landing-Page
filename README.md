# Tanishq Dodiya | Professional Portfolio 🕷️

Ek modern aur responsive landing page jo HTML aur CSS ka upyog karke banaya gaya hai. Isme ek dark theme ke saath Spider-Man inspired hero section hai.

## ✨ Features

* **Responsive Design:** Mobile, tablet aur desktop sabhi screens par sahi dikhta hai.
* **Modern UI:** Dark mode aur blue accent colors ka upyog.
* **Sticky Navbar:** Navigation links (Home, About, Projects, Contact) hamesha top par rehte hain.
* **Hero Section:** Ek impactful background image aur custom buttons.
* **Social Icons:** GitHub, LinkedIn aur Email ke liye direct links.

## 🛠️ Tech Stack

* **HTML5:** Structure ke liye.
* **CSS3:** Styling, Gradients aur Layouts ke liye.
* **Base64 Images:** Image ko directly code mein embed kiya gaya hai taaki external link ki zaroorat na pade.

## 🚀 Kaise Chalayein?

1.  Is repository ko clone ya download karein.
2.  VS Code mein folder ko open karein.
3.  `index.html` file par right-click karke **'Open with Live Server'** par click karein.
4.  Ya phir seedha `index.html` file ko kisi bhi browser mein double-click karke kholein.
